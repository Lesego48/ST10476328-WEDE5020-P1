# ST10476328-WEDE5020-P1
POE PART 1
Project Description
This website was created for Polokwane Paws Rescue, a non-profit animal rescue organisation in Polokwane. The goal of the website is to increase pet adoptions and donations.

Features
- Responsive 5-page website: Home, About, Adopt, Enquiry, Contact.
- Pet gallery with images.
- Contact form with JavaScript validation.
- Embedded Google Maps.

Technologies Used
- HTML5
- CSS3
- JavaScript
- VS Code (from virtual machine)
- GitHub
